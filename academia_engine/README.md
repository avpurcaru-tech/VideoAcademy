# Academia Engine

Platformă modulară pentru generarea automată de videoclipuri educative pentru copii.

## Story Engine

Primește o temă și generează `episode.json` cu `title`, `lyrics`, `storyboard` și
`metadata`.

Configurează `OPENAI_API_KEY` și, opțional, `STORY_MODEL`, apoi rulează:

```powershell
python generate_episode.py "Sistemul solar"
```
